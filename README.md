# 🗺️ MyMap — Personal Interactive Map of Nashik

> 📍 A custom interactive map project built to explore and mark important places around Nashik, Maharashtra, India.

🌐 **Live Demo:** https://mymap1.vercel.app/

---

## 🚀 About The Project

**MyMap** is a personal interactive mapping project focused on **Nashik, Maharashtra**.

I created this project to learn and practice:

- 🗺️ Interactive web maps
- 📍 Custom map markers
- 🎨 Custom SVG/PNG icons
- 💻 HTML, CSS & JavaScript
- 🌍 Geographic data visualization
- 🧭 Map navigation and location-based UI

The map contains personally selected locations and custom markers.

---

## ✨ Features

- 🗺️ Interactive Nashik map
- 📍 Custom location markers
- 🏠 Personal location marker
- 🚉 Railway station marker
- 🛕 Temple marker
- 🏢 Office/workplace markers
- 🏛️ Jail marker
- 🧘 Buddha marker
- 🎨 Custom SVG and PNG icons
- 📱 Web-based map interface
